Craft Agents is designed to be driven entirely from the keyboard. The shortcuts below cover everything from creating a new session to cycling permission modes without reaching for the mouse. All shortcuts use **Cmd** on macOS — if you're on Windows or Linux, substitute **Ctrl** wherever you see Cmd.

<Note>
  Press **Cmd+/** inside Craft Agents at any time to open the interactive shortcuts dialog, which always reflects the most up-to-date list for your installed version.
</Note>

## Session management

Use these shortcuts to create and manage agent sessions.

| Shortcut | Action |
|----------|--------|
| `Cmd+N` | Create a new session |
| `Cmd+/` | Open the keyboard shortcuts dialog |

## Navigation

Move focus between the three main panels of the interface without touching the mouse.

| Shortcut | Action |
|----------|--------|
| `Cmd+1` | Focus the sidebar |
| `Cmd+2` | Focus the session list |
| `Cmd+3` | Focus the chat panel |

## Chat & messaging

Control how you compose and send messages to the agent.

| Shortcut | Action |
|----------|--------|
| `Enter` | Send the current message |
| `Shift+Enter` | Insert a new line (without sending) |

## Permission modes

Craft Agents has three permission modes that control how freely the agent can make changes. You can cycle through them at any time, even mid-conversation.

| Shortcut | Action |
|----------|--------|
| `Shift+Tab` | Cycle through permission modes |

The modes cycle in this order:

| Mode | Display name | Behavior |
|------|-------------|----------|
| `safe` | **Explore** | Read-only — all write operations are blocked |
| `ask` | **Ask to Edit** | Prompts for your approval before making changes (default) |
| `allow-all` | **Auto** | Auto-approves all commands |

<Tip>
  Start a new session in **Explore** mode to let the agent read and analyse your project freely before you decide whether to give it edit access. Switch to **Ask to Edit** or **Auto** when you're ready for it to make changes.
</Tip>

## Windows and Linux

On Windows and Linux, replace **Cmd** with **Ctrl** for all shortcuts in this reference. `Shift+Tab` and `Shift+Enter` are the same on every platform.

| macOS | Windows / Linux |
|-------|-----------------|
| `Cmd+N` | `Ctrl+N` |
| `Cmd+1` | `Ctrl+1` |
| `Cmd+2` | `Ctrl+2` |
| `Cmd+3` | `Ctrl+3` |
| `Cmd+/` | `Ctrl+/` |
