Welcome to Craft Agents — a desktop-first AI agent application built for developers who want to work with powerful AI agents without the friction of CLI tools or bare API wrappers. Craft Agents gives you a polished inbox to manage multiple concurrent AI coding and research sessions, deep integrations with the services you already use, and a highly customizable automation layer — all in a beautiful, fluid UI that gets out of your way.

## How It Works

Craft Agents runs as an Electron desktop app backed by a local (or remote) agent server. When you create a session and send a message, the agent processes your request, streams a response, and executes tools — reading files, running bash commands, calling APIs — all within the permission boundaries you set. Sources extend what the agent can reach: connect a GitHub MCP server, a Slack REST API, or a local filesystem, and the agent can pull context from all of them in a single turn. Skills and Automations let you encode repeatable workflows so the agent knows exactly how you like things done, without you having to re-explain it every time.
