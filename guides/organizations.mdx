Organizations group teammates around shared workspaces. They're local-first — the roster lives in a file on your machine — so you can create an org, invite people, and link a workspace without standing up any backend. When you point Craft Agents at a shared server, invite redemption uses that server so members can join from any device.

## When to use organizations

Use an organization when:

- You want to share workspace context (labels, statuses, skills) with a fixed group of teammates.
- You need role-based control over who can invite others or change org settings.
- You're running a self-hosted Craft server and want per-team scoping.

For solo work, you don't need an org — sessions and workspaces already scope themselves to the current device.

## Roles

Every member has one of three roles:

| Role | Can invite | Can change roles | Can delete org |
|---|---|---|---|
| **Owner** | ✅ | ✅ | ✅ |
| **Admin** | ✅ | ✅ (except owners) | ❌ |
| **Member** | ❌ | ❌ | ❌ |

An org always has at least one owner. Attempting to demote the last owner is rejected.

## Set your identity

Open **Settings → Organizations** and fill in **Username** and **Email**. These fields are how teammates find you when they send invites — the values are stored locally and shared only when you accept an invite.

## Create an organization

<Steps>
  <Step title="Open Settings → Organizations">
    You'll see a list of orgs you belong to and a **Create organization** form.
  </Step>
  <Step title="Name the org">
    Enter a display name (for example, `Acme Research`) and click **Create**. You become the initial owner.
  </Step>
  <Step title="Invite teammates">
    With the org selected, enter an **email or username** and pick **Member** or **Admin**. Click **Send invite** to generate a pending invite token.
  </Step>
</Steps>

## Accept an invite

When someone invites you, they'll share an **invite token**. In **Settings → Organizations**, paste the token into the **Accept invite** field and click **Accept**. The invite is redeemed against your configured Craft server when `CRAFT_SERVER_URL` is set, and locally otherwise.

## Link a workspace to an org

To scope a workspace to an organization:

1. Open the workspace you want to share.
2. Go to **Settings → Organizations** and select the target org.
3. Click **Link this workspace**.

Once linked, workspace-scoped features (labels, statuses, skills) belong to the org and are available to everyone who joins.

<Note>
  Unlinking a workspace only removes the org association — the workspace and its data stay on the machine that created it.
</Note>

## Storage

The org roster lives at `~/.craft-agent/orgs.json`. Workspace-to-org links are recorded in each workspace's `config.json`. Neither file stores secrets — invite tokens are single-use and expire when redeemed.
