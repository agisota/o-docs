title: "Connect LLM Providers to Craft Agents"

Craft Agents is not tied to a single AI provider. You can add as many LLM connections as you like — one for Anthropic Claude, one for a local Ollama model, one for GitHub Copilot — and choose which connection a session uses at any point. This lets you pick the right model for each task: a fast local model for quick lookups, a frontier model for complex reasoning, and a subscription-based provider to avoid per-token costs.

## Supported providers

| Provider | Auth method |
|---|---|
| **Anthropic** | API key or Claude Max/Pro OAuth |
| **Google AI Studio** | API key |
| **ChatGPT Plus / Pro** | Codex OAuth (sign in with your ChatGPT subscription) |
| **GitHub Copilot** | OAuth — device code flow |
| **OpenRouter** | Custom Anthropic-compatible endpoint |
| **Vercel AI Gateway** | Custom endpoint |
| **Ollama** | Local — no API key required |
| **Custom** | Any OpenAI-compatible or Anthropic-compatible endpoint |

<Note>
  OpenRouter, Vercel AI Gateway, Ollama, and custom endpoints are configured through the **Claude / Anthropic API key** connection type by pointing it at a custom base URL. For example, set the base URL to `http://localhost:11434` to route requests through a local Ollama server.
</Note>

## Adding a connection

<Steps>
  <Step title="Open Settings">
    Click the gear icon in the bottom-left of the sidebar, or press `Cmd+,`.
  </Step>
  <Step title="Navigate to Connections">
    Select **Connections** from the Settings sidebar.
  </Step>
  <Step title="Add a new connection">
    Click **Add Connection** and choose your provider from the list.
  </Step>
  <Step title="Enter your credentials">
    Depending on the provider, you will be prompted to:
    - Paste an **API key** (Anthropic, Google AI Studio, OpenRouter)
    - Complete an **OAuth flow** in your browser (Claude Max/Pro, ChatGPT Plus/Pro)
    - Authenticate via **device code** (GitHub Copilot)
    - Enter a **base URL** for self-hosted or proxy endpoints (Ollama, Vercel AI Gateway, custom)
  </Step>
  <Step title="Name the connection (optional)">
    Give the connection a recognisable name — for example, "Claude Sonnet (personal key)" — so you can tell connections apart in the session switcher.
  </Step>
</Steps>

<Note>
  All credentials are stored encrypted on disk using **AES-256-GCM** in `~/.craft-agent/credentials.enc`. Your API keys are never transmitted to Craft Agents' servers.
</Note>

## Setting a default connection

You can set a default connection at two levels:

<Tabs>
  <Tab title="App-wide default">
    Go to **Settings → Connections**, hover the connection you want, and click **Set as Default**. New sessions in any workspace will use this connection unless the workspace has its own override.
  </Tab>
  <Tab title="Per-workspace default">
    Open **Workspace Settings** for the relevant workspace and choose a connection under **LLM model preferences**. This overrides the app-wide default for all sessions in that workspace.
  </Tab>
</Tabs>

## Switching connections per session

You can change which LLM connection a session uses at any point — even mid-conversation.

1. Open the session in the chat view.
2. Click the **connection indicator** in the chat toolbar (it shows the active provider name and model).
3. Select a different connection from the dropdown.

The next message you send will use the newly selected connection. Previous messages in the session are not affected.

<Tip>
  Switching connections mid-session is useful when you want to use a fast model for exploration and then switch to a more capable model when you're ready to make changes.
</Tip>
